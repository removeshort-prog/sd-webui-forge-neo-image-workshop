# Forge Neo 图片工坊

为 **SD WebUI Forge Neo** 增加独立的 **图片工坊** 页签：批量压缩、多格式导出、图片和文字水印、保留透明背景的模型超分。

当前版本：**v1.0.1**。

- **透明图超分**：分别处理彩色图和透明遮罩，保留透明背景。
- **自定义水印**：支持图片模板、等比 Logo、中文文字和全图平铺。
- **批量导出**：WebP、PNG、JPEG、TIFF 可多选，附 ZIP 和 CSV 体积报告。
- **打开输出文件夹**：在预览区下方直接打开最近一次任务的结果目录。

主要适配和验证环境是 Forge Neo + Gradio 4.40；旧版 Forge / Gradio 3 未完成完整验证。

## 安装

### 从 GitHub 安装（推荐）

在 Forge Neo 的 **扩展 → 从网址安装** 中输入：

```text
https://github.com/removeshort-prog/sd-webui-forge-neo-image-workshop
```

安装后完整退出并重新启动 Forge Neo，打开 **图片工坊** 页签。

也可以在 Forge Neo 根目录执行：

```bash
git clone https://github.com/removeshort-prog/sd-webui-forge-neo-image-workshop.git extensions/sd-webui-forge-neo-image-workshop
```

### 手动安装

1. 从 GitHub 的 **Code → Download ZIP** 下载并解压。
2. 将包含 `scripts` 的文件夹重命名为 `sd-webui-forge-neo-image-workshop`，放入 Forge Neo 根目录的 `extensions` 文件夹。
3. 完整退出并重新启动 Forge Neo。

目录结构：

```text
Forge Neo/extensions/sd-webui-forge-neo-image-workshop/
  scripts/image_workshop.py
  forge_image_workshop/
  style.css
```

Windows 也可以双击插件中的 `安装到Forge.bat`，粘贴 Forge Neo 根目录路径。安装器仅复制文件；目标插件或旧名称插件已存在时会停止，避免重复安装。通过 Git 安装的版本可用扩展管理器更新；手动更新时先把旧插件移出 `extensions`，再安装新版本。不要把两个版本同时放在 `extensions`。

插件复用 Forge 的 Pillow、Gradio 和已注册超分模型，不安装依赖，不需要运行 ComfyUI，不修改 Forge 源码。卸载时删除本插件文件夹并重启，已导出的图片保留。

## 快速开始

### 只压缩图片

上传一张或多张图片 → 倍率 `1` → 选择 `WEBP` → 质量 `85～92` → 开始批量处理。

可以一次选择多个输出格式。处理完成后可下载单图、ZIP 和 CSV 体积报告，原文件不被覆盖。

### 透明图超分

1. 上传透明 PNG 或透明 WebP。
2. 倍率选择 `2`，超分模型选择 `RealESRGAN_x2`（以列表中的名称为准）。
3. 透明通道选择 **模型遮罩（匹配 ComfyUI）**。
4. 输出选择 PNG，或 WEBP 并开启无损。
5. 先点 **试处理首张**，确认边缘后再批量处理。

例如可将 `RealESRGAN_x2.pth` 放入 `models/ESRGAN/`。其他模型请放入当前 Forge Neo 支持的模型目录并重启；“刷新列表”仅刷新已经由 Forge 注册的模型，不重新扫描磁盘。

透明流程采用 ComfyUI 中的彩色图与透明遮罩分别超分逻辑：

```text
RGBA 输入 ─ RGB ─ 选定模型超分 ──────────────┐
          └ 1-Alpha ─ 同一模型超分 ─ 红通道 ─ 1-遮罩 ─ 合并 RGBA
```

ComfyUI 的 MASK 表示透明程度，因此模型遮罩路线使用 `1-Alpha`，合并时再次反转。不会把透明背景预先铺成黑色或白色。全不透明/恒定透明度图片会跳过无意义的遮罩模型调用。**Lanczos（快速）** 选项仅对透明通道插值，彩色部分仍使用选中的模型。

AI 只在倍率大于 1 时运行；倍率 1 保持尺寸，倍率小于 1 使用普通缩小。Lanczos / Nearest 始终属于普通缩放。输出尺寸为 `round(原尺寸 × 倍率)`，不强制对齐到 8 的倍数。

模型遮罩会改变边缘覆盖率，和普通插值可能有不同视觉效果；“匹配 ComfyUI”指相同处理逻辑，不保证跨框架的逐像素一致。若边缘出现晕圈，可尝试 Lanczos 透明通道。输入文件透明像素里原本带有的底色也会影响模型边缘。

### 图片模板与文字水印

- **按比例匹配模板并铺满**：上传多个横版、竖版模板，自动选择长宽比最接近底图的一张，拉伸铺满画布。
- **等比 Logo**：保持 Logo 比例，按底图宽度百分比缩放，支持九宫格位置、边距、不透明度。
- **文字水印**：自定义中文、多行内容、字体、颜色、字号、不透明度、旋转和全图平铺，可与图片水印同时使用。
- **保持透明轮廓**：默认开启，水印仅改变主体颜色，维持超分后图像的 Alpha。关闭后，水印可以绘制到原本完全透明的区域。

Windows 优先使用微软雅黑/黑体。Linux/macOS 自动寻找常见中文字体；找不到时会提示上传 TTF/OTF/TTC。上传字体需要包含水印用到的字形。

处理顺序是 **读取并校正方向 → 缩放/超分 → 图片水印 → 文字水印 → 编码压缩**。水印在最终尺寸上绘制，避免文字再次缩放。颜色合成采用正确的 Alpha 运算，不重复乘水印透明度。

## 格式与压缩

| 格式 | 透明背景 | 设置 |
| --- | --- | --- |
| WebP | 支持 | 有损质量 1～100，或无损；无损时质量值调节编码工作量 |
| PNG | 支持 | 无损，压缩级别 0～9；越高通常越慢、越小 |
| JPEG | 不支持 | 质量 1～100；透明区域填充选定底色 |
| TIFF | 支持 | Deflate 无损压缩 |

压缩不承诺一定比输入更小。超分、添加内容、更换格式或输入本来已高度压缩，都可能增加文件体积。CSV 逐文件列出原始和输出字节数。

输入支持当前 Pillow 可读取的 PNG、WebP、JPEG、TIFF、BMP，以及环境已支持的 AVIF。动画、多帧 WebP、多页 TIFF 会报错并跳过，不会静默只处理第一帧。

默认清除 metadata、EXIF、ICC 和生成提示词。关闭清除后，尽量保留 EXIF/ICC；PNG 还保留文本元数据（包括 `parameters`）。不保证跨格式保留所有私有元数据，也不转换 PNG 提示词到 JPEG/WebP EXIF。图像按 8 位 RGBA 处理，不适合需要保留 16 位/HDR 数据的工作流。

## 批量与输出

- 上传多张，或选择本机文件夹；支持递归和自然排序/修改时间排序。
- 遵守 Forge 的 `--hide-ui-dir-config`：开启后不提供本机文件夹和自定义输出目录。
- 默认保存在 `Forge/outputs/image-workshop/日期时间-唯一编号/`。
- 序号加原文件名避免重名，每个任务使用独立文件夹；输入目录下的输出根目录会排除出递归扫描。
- 图片平铺到本次任务文件夹，不复刻输入子目录结构。
- 坏图或单张模型错误记入 CSV，继续下一张；取消时保留已导出的结果。
- “停止”只请求取消本会话在本面板的任务，需要等当前模型调用结束。
- 结果面板展示前 20 张实际编码后的图片缩略图；单文件下载展示前 100 个，ZIP 包含全部输出。
- 预览下方的 **📂 打开输出文件夹** 打开本会话最近一次任务的实际结果目录，试处理和已停止任务同样适用。尚未处理时，打开当前填写的输出目录或默认目录；目录不存在时自动创建。按钮调用运行 Forge Neo 那台电脑的文件管理器。
- 开启 `--hide-ui-dir-config` 时，打开文件夹按钮也会隐藏并由后端禁用。
- 试处理首张采用完整设置，也会保存文件；输出历史由用户自行清理。

## 显存和尺寸

复用 Forge 的超分分块设置。显存不足时在 Forge 设置里调整 ESRGAN tile / overlap，使用较小图或 2× 模型。选择 4× 模型只放大 2× 时，模型仍先生成 4× 中间图再缩小。

默认单张输入、输出及模型中间图上限为 6400 万像素，可以在面板调整；像素上限不是显存保证。模型加载失败且返回原图时，本插件会报错，避免把普通插值误当成功超分。
